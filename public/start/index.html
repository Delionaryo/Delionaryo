OFFICIAL ACCOUNT CREATION

Create your DELIONARYO account.

This Start Page is the official public registration point. Your verified mobile number is your primary access identity. Your permanent Core member ID and Wallet account remain the same even if your mobile number changes later through an approved recovery flow.

If you already have a DELIONARYO account, use Existing Account / Verify Phone. Do not create another account.

The mobile number is not treated as verified until the SMS OTP succeeds. By creating an account, you may receive DELIONARYO account, learning and educational messages.

Verify your primary mobile number.

We will send an SMS code to the mobile number you enter. Verification links the current authenticated account to the Core member and its single Wallet account. It does not create a second Wallet.

EXISTING ACCOUNT

Use the account you already have.

Sign in first. We will then attach and verify your primary mobile on this same Auth user, Core member and Wallet account.

Recover or activate your existing DELIONARYO account.

Enter the email already attached to the account. We will send a secure password recovery link. This keeps the same account ID and existing data.

Set a new DELIONARYO password.

The secure recovery link has verified this existing account. Set your password, then verify your primary mobile on the same account.
